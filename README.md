## Legend

**Type**, following [Conventional Commits](https://www.conventionalcommits.org/):

| Type | Meaning |
|------|---------|
| `fix` | Bug fix |
| `feat` | New feature |
| `perf` | Performance improvement |
| `refactor` | Code change with no behaviour change |
| `test` | Tests added or fixed |
| `docs` | Documentation only |
| `chore` | Build, CI, tooling, dependencies |

**Status**

| Status | Meaning |
|--------|---------|
| ✅ Merged | Accepted into the project |
| 🟡 Open | Under review |
| ⛔ Closed | Closed without merging (kept for transparency) |

**Date** is the month the PR was merged, or opened if it isn't merged yet.
